ANNOTATED OVERLAY (what each piece is for)
------------------------------------------
files/  (path-preserving overlay onto the OpenWrt tree)
  target/linux/realtek/
    files-4.14/arch/mips/pci/pci-realtek.c
                  ** The PCIe RC bring-up rewrite ** — vendor reset sequence
                  reverse-engineered from the stock kernel: PHY digital-reset
                  release to SR+0x100, device reset = SR+0x50 bit1 (300ms), the
                  25/40MHz PHY MDIO tuning off the bootstrap reg, and a clean
                  bail if the link never trains. This is what makes the RTL8822BE
                  enumerate.
    files-4.14/arch/mips/include/asm/mach-realtek/realtek_mem.h
                  Adds REALTEK_SR_MDIORST 0x100 (used by pci-realtek.c).
    files-4.14/drivers/net/ethernet/rtl819x/{rtl819x-eth.c,rtl819x_swnic.c/.h,
                  rtl819x_regs.h,Kconfig,Makefile}
                  The carved RTL8197F NIC driver: mbuf-ring CPU-port DMA, switch
                  VLAN-membership forwarding, IRQ-driven NAPI + a fast RX watchdog
                  poll, and the SBFCR/PBFCR flow-control + GDSR congestion drain.
    files-4.14/drivers/net/ethernet/rtl819x/{rtl865x_asichal.c/.h}
                  ** The ASIC L3/L4 table engine (M6.6) ** — reverse-engineered
                  netif/route/nexthop/ARP/L2/NAPT/extIP table access + gw_prog,
                  the stock-equivalent HW routing/NAT datapath (/proc/rtl865x_gw),
                  and the /proc/rtl865x_{napt,fabric} diagnostics.
    files-4.14/drivers/net/ethernet/rtl819x/{rtl819x_hwnat.c/.h}
                  ** Conntrack-driven hardware NAT offload (M6.6) ** — the
                  ndo_flow_offload glue that installs/reaps per-flow ASIC NAPT
                  rows so established flows forward + source-NAT in silicon.
                  Runtime param rtl819x.hwnat (module default 0, but the shipped
                  dir842-asic service arms it at boot since R4). MEASURED 891/896 Mbit
                  at 0.0% of payload bytes through the CPU.
    generic/files/drivers/net/phy/{rtl8367b.c,rtl8366_smi.c/.h}
                  RTL8367S swconfig management + a forced-on debugfs for live
                  8367S register access (the key bring-up diagnostic).
    dts/RTL8197F.dtsi        pcie0(RTL8822BE)/pcie1(disabled)/pcie_clk=25MHz + eth node.
    dts/GWR1200ACV1.dts      board dts (console=ttyS0,38400 bootarg).
    patches-4.14/0006-net-add-rtl819x-eth.patch   Kbuild wiring for the eth driver.
    rtl8197f/config-4.14     CONFIG_NET_RTL819X + PCI_SUPPORT.
    Makefile                 FEATURES += pci.
    image/Makefile           cvimg-kernel-cr6b + dlink-md5-sign image recipes.
    base-files/etc/uci-defaults/99-dir842-m5
                  First-boot gateway config: LAN eth0.2 192.168.0.1 + WAN eth0.1
                  a DHCP-client WAN (both MACs pinned to the ASIC netifs),
                  the 8367S VID cascade, fw3 flow_offloading_hw, and an OPEN (unencrypted) 5 GHz
                  AP on the RTL8822BE (pinned wlan MAC — efuse is blank).
    base-files/etc/{init.d/dir842-asic,rc.local,sysctl.d/30-hwnat.conf}
                  init.d/dir842-asic (START=97) OWNS boot bring-up since R4:
                  MAC poll -> swconfig apply -> fabric_reset 3 -> gw_prog ->
                  L2 warm -> arm hwnat. rc.local is intentionally EMPTY (its
                  inline copy was removed in R4). sysctl enables
                  nf_conntrack_acct (so offload can be observed).
  package/kernel/mac80211/patches/realtek/
    03-rtw8822b-blank-efuse-rfe.patch     default RFE type 2 on a blank efuse.
    04-rtw88-random-mac-blank-efuse.patch random MAC when the efuse MAC is invalid.
  package/firmware/linux-firmware/qca_ath10k.mk
